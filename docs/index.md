# UI Docs

Living specs and decisions for this site's pages, components, and fragments.

See [about this system](about-this-system.md) for how requirements, decisions, and IDs work here.

## Categories

- **Pages** — full pages made of multiple components.
- **Components** — functional units made of fragments (grouped by type, e.g. modals, buttons, forms).
- **Fragments** — smallest reusable pieces (icon, label, avatar, input field).

Browse the folders in the nav to find a specific page/component/fragment's `requirements.md` and `decisions.md`.
